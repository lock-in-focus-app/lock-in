# Brand mock-ups

Logo ideas for Seiza and places a little Japanese could go. Not final art: the type in any logo would be turned into outlines, and any Japanese checked by a native speaker, before it ships.

**To view it**, start the static server from the repository root and open <http://localhost:4330/brand/>:

```bash
pnpm --filter @lock-in/desktop exec vite ../../prototypes --port 4330
```

- **Logos:** the kneeling constellation, ensō and star, star in orbit, an S in the stars, a seal, and a wordmark. Each is shown large, as an app icon, at 32px and 16px, and in a browser tab.
- **Japanese touches:** the reading under the website's mark, 星座 down the frame's edge, a gloss in a corner, one word on the Sky section, and the reading in the app and extension.
